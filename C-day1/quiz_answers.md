### Q1-2. hello.c 를 컴파일해서 hello 라는 이름의 실행파일을 만들고 싶습니다. 올바른 명령은 무엇입니까?

**① gcc hello.c -o hello** ✅  
② gcc -c hello.c hello  
③ gcc hello.c > hello  
④ gcc --name hello hello.c  

> **정답: ① gcc hello.c -o hello**  
> 해설: -o 뒤가 출력 파일 이름입니다. -c 는 오브젝트 파일까지만 만들고 멈추는 옵션이고, > 는 셸 리다이렉션이라 gcc 옵션이 아닙니다.

### Q1-3. main 함수의 return 값을 7 로 바꾸고 아래처럼 실행했습니다. 두 번째 줄 echo 가 출력하는 값은 무엇입니까?

```c
int main(void) {
    printf("센서 초기화 실패\n");
    return 7;
}

$ ./hello; echo $?
```

① 0  
**② 7** ✅  
③ 에러 메시지  
④ 아무것도 출력되지 않음  

> **정답: ② 7**  
> 해설: main 의 반환값은 프로세스의 종료 코드가 되고, 셸 변수 $? 로 직전 프로그램의 종료 코드를 읽을 수 있습니다. 0 은 정상, 0 이 아니면 비정상 종료라는 약속입니다.


> **정답: ③ implicit declaration 경고 또는 에러가 난다 (C99 이후 에러)**
